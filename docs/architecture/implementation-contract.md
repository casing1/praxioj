# Milestone 1 implementation contract

Shared contract for implementation; maintained with the final code.

- Distribution: `praxioj-framework`, Python import `praxioj`, at `packages/framework`. Pydantic only. Independent modules: core, problems, runtime, tracing, evaluation, execution. No framework imports of platform/FastAPI/SQLAlchemy.
- API distribution: `praxioj-api`, Python import `praxioj_api`, at `apps/api/src`. FastAPI + synchronous SQLAlchemy 2, PostgreSQL + psycopg. SQLite only for fast tests. Alembic owns schema changes, no create_all at application startup.
- API prefix `/api`. `GET /health` too if useful. UI uses relative `/api`, Vite proxy in dev and nginx proxy in Compose.
- Local development only, HTTP loopback hosts, no production auth. Server-issued random HttpOnly SameSite=strict cookie `praxioj_dev_identity` separates browser-local participants. Store token hash in User; never trust supplied user IDs. State-changing requests validate Origin when supplied, reject foreign origins. Hidden session/evaluation resources return 404 across identities. Identity is a local demo convenience, not login/production authorization.
- POST /api/sessions {problem_id, version} -> 201 SessionDetail. Creates browser identity when needed. SessionDetail {id, problem_id, problem_version, status: active|submitted, messages: [{id, role, content, created_at}], submission_id: string|null, evaluation_id: string|null, created_at}.
- GET /api/problems -> array ProblemPublic. GET /api/problems/{problem_id}?version=... -> ProblemPublic. ProblemPublic {id,version,title,description,category,difficulty,initial_resources:[{name,content,media_type}],allowed_ai_capabilities:[string],allowed_tools:[string],resource_limits:{max_messages,max_message_chars,max_submission_chars},submission:{kind:'text',instructions},evaluation:{evaluator_id,evaluator_version,criteria:[{id,title,description,max_score}]}}. Private criteria config never serialized publicly.
- GET /api/sessions/{session_id} -> SessionDetail.
- POST /api/sessions/{session_id}/messages {content} -> {user_message:{id,role,content,created_at},assistant_message:{id,role,content,created_at}}. Session must be active; transaction locks session row for sequencing and request counts. Provider receives persisted conversation; mock only.
- GET /api/sessions/{session_id}/trace -> array TraceEnvelope sorted by sequence_number. Server allocates sequences atomically under session lock; unique (session_id,sequence_number) and event_id. No external event ingestion in M1. Trace reads require owning identity.
- POST /api/sessions/{session_id}/submissions {content} -> 201 {submission_id,evaluation_id}. Exactly one immutable final submission per session; repeated submission 409. Trusted inline evaluator only, completed synchronously in same transaction. GET /api/evaluations/{evaluation_id} -> EvaluationResult including session_id, submission_id, problem_id, problem_version.
- API errors standard FastAPI detail with user-safe string or validation errors; do not leak DB errors/evaluator secrets.
- Problem package `manifest.json` only, schema_version '1.0', `id`, version (semver), public fields above plus evaluation.criteria[*].config {required_terms:[string]}. Private config used by trusted evaluator. No dynamic imports or files referenced by manifest. Inline initial resources only. CLI registration validates package and content hash; same id/version+hash idempotent, changed manifest under existing version rejected.
- Framework contracts root implements:
  - `praxioj.problems`: ProblemManifest, load_problem_package(path)->ProblemManifest, manifest_digest(manifest)->str, public_problem(manifest)->dict.
  - `praxioj.runtime`: Message(role,content), ModelConfig(provider='mock',model='praxioj-mock-v1',temperature=0), MockProvider, AIRuntime(provider). async respond(messages:list[Message],config:ModelConfig,max_messages:int)->ProviderResponse(content,model,usage). Usage(input_tokens,output_tokens) estimated mock units; no external network/tools.
  - `praxioj.tracing`: EventType string Enum (all requested upper-case events), TraceEnvelope(event_id UUID default, session_id str, sequence_number int>=1, event_type, timestamp aware UTC default, payload dict, schema_version='1.0', source='server'|'external', actor str='system', resource_ids dict default). redact_payload(payload)->dict, with best-effort sensitive key/token redaction, not a secret scanner.
  - `praxioj.evaluation`: SubmissionData(id:str,content:str,sha256:str), EvaluationInput(problem:ProblemManifest,submission:SubmissionData,artifacts:list default,trace:list[TraceEnvelope] default,configuration:dict default). EvaluationEngine().evaluate(input)->EvaluationResult. EvaluationResult(id UUID default,status:'completed'|'failed'|'unsupported',score:float|null,maximum_score:float|null,criteria:list[CriterionResult],feedback:list[str],evidence:list[EvidenceReference],evaluator_id,evaluator_version). CriterionResult(id,title,score,maximum_score,passed,feedback,evidence:list). EvidenceReference(kind:'submission'|'trace'|'artifact',reference:str). Trusted registry only `builtin.text-rubric` version `1.0.0`; required_terms case-insensitive substring matching all terms yields criterion max points else zero. Failure feedback must not reveal private required terms.
  - execution protocols only, all operational methods raise explicit not implemented in UnavailableExecutionBackend.
- Session event lifecycle SESSION_STARTED, USER_MESSAGE + ASSISTANT_MESSAGE, ARTIFACT_UPDATED + SUBMISSION_CREATED + EVALUATION_COMPLETED + SESSION_ENDED. Store raw content only in messages/submissions, trace uses redaction. Trace artifacts/submissions contain hashes and identifiers instead of full submitted text. Model config, problem/evaluator versions, manifest/content hashes, environment metadata preserved.
